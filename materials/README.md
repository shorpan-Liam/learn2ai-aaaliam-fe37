# React 入门课程资料

本目录提供一组面向前端初学者的 React 入门讲义。建议学习者已经掌握 HTML、CSS 和 JavaScript 基础，尤其是变量、函数、数组方法、对象、模块与异步编程。

## 建议学习顺序

1. [01-react-overview.md](./01-react-overview.md)：认识 React、理解声明式 UI 和组件化思想。
2. [02-jsx-and-components.md](./02-jsx-and-components.md)：学习 JSX、函数组件和组件拆分。
3. [03-props-state-events.md](./03-props-state-events.md)：理解 Props、State、事件处理和单向数据流。
4. [04-hooks-and-effects.md](./04-hooks-and-effects.md)：学习常用 Hooks、副作用和数据请求。
5. [05-project-workflow.md](./05-project-workflow.md)：了解 React 项目结构、调试、质量保障与后续路线。

## 教学建议

- 每份资料可安排 1 至 2 课时。
- 讲解代码后，让学生先预测页面行为，再实际运行验证。
- 练习优先采用“小步修改”，避免学生一开始就陷入大型项目结构。
- 强调 JavaScript 基础。多数 React 学习困难，本质上来自数组、对象、闭包或异步编程不熟练。

## 推荐实践项目

完成全部资料后，可组织学生开发一个“学习任务清单”：支持新增任务、切换完成状态、按状态筛选、保存到浏览器本地，并展示加载与空状态。
