# React 迷你待办清单

一个使用 React 和 Vite 实现的响应式待办清单。支持新增、完成切换、删除、分类筛选和浏览器本地持久化。

## 安装与启动

```bash
npm install
npm run dev
```

终端会输出本地访问地址，通常为 `http://localhost:5173`。

## 操作方法

1. 在输入框中填写任务，按回车或点击“添加”。纯空白内容会被拒绝。
2. 点击任务左侧圆形按钮切换完成状态。
3. 点击任务右侧删除按钮移除任务。
4. 使用“全部”“未完成”“已完成”切换筛选视图。
5. 任务会写入 `localStorage`，刷新页面后仍然保留。

## 验证步骤

```bash
npm test
npm run build
```

手动验证时依次测试新增、空白校验、完成切换、三种筛选、删除和刷新后的数据恢复，并分别检查手机与桌面宽度。

## 组件与状态设计

- `App`：持有任务数组和当前筛选条件，负责不可变状态更新及 `localStorage` 同步。
- `TaskForm`：管理输入框内容和校验提示，通过回调向父组件提交任务。
- `FilterTabs`：根据 props 展示并切换三种筛选条件。
- `TaskList`：渲染列表或对应筛选条件的空状态。
- `TaskItem`：展示单项任务，并通过回调触发完成切换和删除。

完成数量、剩余数量和筛选后的任务列表均由现有 state 在渲染期间计算，不额外存入 state，避免数据不同步。
