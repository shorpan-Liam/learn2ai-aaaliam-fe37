# React 技术调研报告

## 目标

结合课程资料完成一篇约 200 字的 React 调研报告，概括 React 的用途、核心思想和适用场景，并形成自己的技术判断。

## 要求

1. 阅读 `materials/01-react-overview.md`，并从 `materials/02-jsx-and-components.md`、`materials/03-props-state-events.md`、`materials/04-hooks-and-effects.md`、`materials/05-project-workflow.md` 中至少选择一份补充阅读。
2. 报告正文使用中文撰写，字数控制在 180–220 个汉字；标题、标点、资料名称和参考资料列表不计入字数。
3. 正文应回答：React 主要解决什么问题、有哪些核心概念、适合哪些前端开发场景。
4. 至少写出一项 React 的优势和一项使用限制或学习难点，不能只罗列课程资料原句。
5. 报告末尾增加“参考资料”小节，列出实际阅读的 `materials/` 文件路径。
6. 使用自己的语言组织内容，并在提交前自行核对字数和事实表述。

## 提交标准

- 提交一个 Markdown 文件，建议命名为 `react-research-report.md`。
- 文件包含报告标题、180–220 个汉字的正文和“参考资料”小节。
- 正文完整覆盖 React 的用途、核心概念、适用场景、优势及限制或学习难点。
- 参考资料至少包含两份本课程 `materials/` 下的讲义。
- 成果放在 `work/<用户UUID>/42923ec8-55f0-47ba-af10-5cb254ca152f/` 目录中，并在应用内提交成果、确认分享本次学习过程。

## 评分关注点

- 内容准确，能够联系课程资料。
- 观点完整，不是概念的机械堆砌。
- 字数符合要求，表达清楚、结构紧凑。
- 参考资料标注明确，能够区分资料观点与个人判断。
