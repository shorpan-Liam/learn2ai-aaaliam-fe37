# React 迷你待办清单网页

## 目标

使用 React 实现一个小型、可在浏览器中运行的待办清单网页，练习组件拆分、状态管理、事件处理、列表渲染和本地数据持久化。

## 要求

1. 阅读 `materials/02-jsx-and-components.md`、`materials/03-props-state-events.md`、`materials/04-hooks-and-effects.md` 和 `materials/05-project-workflow.md`。
2. 创建一个能够通过 `npm install` 和 `npm run dev` 启动的 React 项目，可使用 Vite 或课程中已有的等效工具链。
3. 页面至少包含输入框、添加按钮、待办列表和任务统计信息。
4. 用户能够新增非空任务、切换任务的完成状态，以及删除任务；空白内容不得被添加。
5. 提供“全部”“未完成”“已完成”三种筛选视图，并正确显示当前筛选结果。
6. 使用 `localStorage` 保存任务。刷新页面后，已经添加的任务及完成状态仍应保留。
7. 至少拆分出两个 React 组件，并合理使用 `props`、`useState` 和 `useEffect`，避免直接修改状态对象或数组。
8. 页面应具有清晰的视觉层级，并在常见手机宽度和桌面宽度下正常使用，不出现明显溢出或控件重叠。
9. 在项目中提供 `README.md`，写明安装、启动、操作和验证步骤，并简要说明组件划分与状态设计。

## 评分关注点

- 网页能否稳定运行，核心交互是否完整正确。
- React 组件、状态、属性和副作用的使用是否合理。
- 界面是否清晰、响应式布局是否可用。
- `README.md` 是否提供了可复现的运行与验证说明。
